## Alcance de esta fase

Se documentan únicamente las decisiones necesarias para diseñar y construir las siguientes fases. Los únicos servicios creativos son **Diseño Gráfico**, **Video** y **Render / Modelado 3D**.

## Convenciones

- “Debe” identifica una regla requerida.
- “Recomendación” identifica una decisión propuesta pendiente de validación.
- Las rutas son conceptuales; no son rutas Laravel implementadas.
- Mermaid se usa para expresar relaciones y flujos; los diagramas se mantienen acotados para conservar legibilidad.
