# Tipografía

Familia preferida: Inter; fallback local: `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`. No se depende de una descarga externa.

| Nivel | Tamaño / línea / peso | Uso |
|---|---|---|
| Display | 48 / 56 / 700 | Presentaciones puntuales |
| H1 | 36 / 44 / 700 | Encabezado principal |
| H2 | 30 / 38 / 700 | Sección |
| H3 | 24 / 32 / 600 | Sub-sección |
| Body | 14 / 22 / 400 | Contenido general |
| Label | 13 / 18 / 500 | Campos y controles |
| Caption | 12 / 18 / 400 | Metadatos |

Folios y datos técnicos usan una familia monoespaciada y no deben competir con el título.
