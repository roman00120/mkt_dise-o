# Colores

Los tokens semánticos están en `resources/css/tokens.css`. La interfaz principal usa fondo `#090B10`, superficies escalonadas y rojo corporativo `#E30613` para acciones primarias.

Los colores de servicio son acentos: Diseño `#8B5CF6`, Video `#F43F5E` y Render `#06B6D4`. No deben pintar tarjetas completas ni ser la única señal de estado.

Estados: éxito `#22C55E`, advertencia `#F59E0B`, error `#EF4444`, información `#3B82F6`. Validar contraste WCAG 2.2 AA en cada combinación final.
