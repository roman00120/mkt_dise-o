# Responsive

Breakpoints conceptuales: Mobile 320–639px, Tablet 640–1023px, Desktop 1024–1439px y Large 1440px+.

- Sidebar se oculta en móvil y se reemplaza por menú de secciones.
- Grids pasan a una columna en móvil y dos/cuatro según espacio.
- Tablas permiten scroll contenido controlado y deben tener alternativa card en pantallas funcionales.
- Kanban mantiene columnas desplazables horizontalmente, sin forzar toda la página.
- Drawers ocupan el ancho completo en móvil; modales usan padding de 16px.
- Stepper mantiene scroll horizontal y etiquetas legibles.
- El UI Kit usa `min-w-0`, wrapping y overflow localizado para evitar scroll horizontal global.
