# Componentes

- `dashboard.metric-card`: métrica con icono, valor y contexto.
- `dashboard.section`: encabezado semántico y acción opcional.
- `dashboard.service-card`: servicio creativo y CTA.
- `dashboard.attention-item`: folio, estado, prioridad, contexto y acción.
- `dashboard.activity-item`: actividad con fecha relativa y exacta accesible.
- `dashboard.quick-action`: acceso rápido.
- `deliverable.review-card`: archivo y acción de revisión.
- `request.list-item`: fila desktop y card responsive.

Los componentes reutilizan `x-ui.card`, `x-ui.badge`, `x-ui.empty-state`, `x-ui.avatar`, `x-request.status-badge`, `x-request.service-badge` y `x-request.priority-badge`.
