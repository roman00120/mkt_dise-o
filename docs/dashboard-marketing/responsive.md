# Responsive

El layout usa sidebar fija desde `lg` y drawer móvil con backdrop, cierre por botón, click exterior y Escape. Las métricas pasan de cuatro columnas en desktop a dos en tablet y una en móvil. Las solicitudes usan tabla desde `lg` y cards apiladas en tamaños menores.

Se usan paddings de 16–32px, botones con mínimo 44px de alto y grids fluidos. Los filtros tienen desplazamiento horizontal contenido para conservar targets táctiles.
