# Accesibilidad

El dashboard incluye skip link, landmarks (`aside`, `nav`, `header`, `main`, `section`), `aria-current`, nombres accesibles para botones e iconos decorativos, foco visible heredado del Design System, `time` con `datetime` y fecha exacta en `title` para actividad.

El drawer y menús se controlan con Alpine, soportan Escape y click exterior. La interfaz no depende únicamente del color: estados incluyen texto, icono y etiquetas. Se respetan las reglas globales de movimiento reducido del Design System.
