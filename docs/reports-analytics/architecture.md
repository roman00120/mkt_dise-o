# Arquitectura

`ReportScopeService` aplica alcance; `ReportFilterService` normaliza periodos; `ReportMetricsService` calcula agregados; `DataQualityService` reporta inconsistencias; `StatusPeriodService` materializa duración histórica; `SlaService` evalúa políticas. SQLite usa consultas agregadas y percentiles compatibles en PHP para la Fase 11 local.
