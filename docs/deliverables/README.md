# Fase 8 · Entregables

Implementa entregables reales, versiones inmutables después de revisión, archivos privados, revisión interna, revisión de Marketing, correcciones, aprobación y cierre. No incluye chat, anotaciones visuales, comparador avanzado ni Fase 9.

## Flujo

Creativo crea versión draft, adjunta archivos y la envía a revisión interna. Supervisor aprueba o solicita cambios. Una versión aprobada internamente se envía a Marketing. Marketing aprueba o crea una corrección; cada corrección origina una nueva versión.
