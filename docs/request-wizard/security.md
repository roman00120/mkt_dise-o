# Seguridad

- CSRF en formularios.
- Policies para propietario, edición y archivos.
- Mass assignment protegido.
- Enums y catálogos para impedir servicios/estados arbitrarios.
- Storage privado y nombres generados por Laravel.
- MIME, extensión y tamaño validados.
- Transacción en creación, actualización y envío.
- Un envío posterior a `pending` no vuelve a editarse.
- No se exponen paths internos ni archivos directamente.
