# Accesibilidad

El wizard reutiliza el stepper del Design System, fieldsets, legends, labels visibles, radios nativos, targets de 44px, focus visible y navegación por teclado. El upload tiene alternativa de selección de archivo, no depende sólo de drag and drop y muestra errores como alertas.

El stepper muestra el paso actual y la navegación no depende únicamente del color.
